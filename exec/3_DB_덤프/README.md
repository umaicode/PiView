# 3. DB 덤프

## 1. 포함 파일

- `piview_dev_20260329.sql`
- `chromaDB/full_18749_20260324_1918/`

## 2. 덤프 대상

- `piview_dev_20260329.sql`
  - MySQL `piview_dev` 스키마와 데이터 덤프 파일
  - 피부 분석, 설문, 보유 제품, 제외 제품, 루틴, 추천, 로그 기반 추천에 필요한 서비스 데이터를 포함한다
  - 확인 시점 기준 `24`개 테이블이 존재한다

- `chromaDB/full_18749_20260324_1918/`
  - Chroma 벡터 DB 백업본
  - AI 검색/챗봇 retrieval에 사용하는 벡터 인덱스와 메타데이터를 포함한다
  - 확인 컬렉션명은 `products`다
  - 포함 파일 예:
    - `chroma.sqlite3`
    - `index.log`
    - `e2386520-ae9e-44aa-8f06-36d6b3556790/*`

## 3. 데이터 설명

### 3-1. MySQL 덤프

`piview_dev_20260329.sql`은 PiView dev 환경의 관계형 서비스 DB 덤프다.
사용자 정보, 피부 분석 결과, 설문 결과, 보유 제품, 제외 제품, 루틴, 제품 메타데이터, 추천 연산에 필요한 관계형 데이터를 포함한다.

### 3-2. Chroma 백업본

`chromaDB/full_18749_20260324_1918/`은 AI 검색과 챗봇 retrieval에 사용하는 벡터 DB 백업본이다.
제품 문서 임베딩, 인덱스 로그, 벡터 검색용 파일 세트를 포함한다.
